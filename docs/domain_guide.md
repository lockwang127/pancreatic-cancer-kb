## 1. 流行病学 (Epidemiology)

### 核心知识点
- 中国发病率: 11.87万/年 (2022)
- 中国死亡人数: 约12万/年
- 5年生存率: 约12%
- 病死比 >100%

### 危险因素
| 因素 | 风险倍数 | 证据等级 |
|------|----------|----------|
| 吸烟 | 2-3倍 | A级 |
| 慢性胰腺炎 | 高 | B级 |
| 糖尿病 | 中 | B级 |
| BRCA突变 | 2-6倍 | A级 |

### 好发人群
- 年龄: 60-80岁
- 性别: 男性略多
- 部位: 胰头60-70%

## 2. 诊断评估 (Diagnosis)

### 影像学检查
| 检查 | 用途 | 优先级 |
|------|------|--------|
| 增强CT | 分期、可切除性评估 | 首选 |
| MRI/MRCP | 胆道、囊性病变 | 补充 |
| EUS | 早期病变、活检 | 高敏感性 |

### 生物标志物
| 标志物 | 敏感性 | 特异性 | 临床应用 |
|--------|--------|--------|----------|
| CA19-9 | 70-90% | 70-80% | 诊断+监测 |
| CEA | 40-60% | 70-80% | 辅助 |
| CA125 | - | - | 转移监测 |

### 病理类型
- 导管腺癌: >90%
- 腺泡细胞癌: 1-2%
- 神经内分泌肿瘤: <1%
- 囊性肿瘤: 浆液性/粘液性

## 3. 分期系统 (Staging)

### AJCC第8版TNM分期

#### T分期
| 分期 | 大小/特征 |
|------|-----------|
| T1 | ≤2cm，局限于胰腺 |
| T2 | >2cm且≤4cm |
| T3 | >4cm或超出胰腺 |
| T4 | 累及腹腔干/肠系膜上动脉 |

#### N分期
| 分期 | 定义 |
|------|------|
| N0 | 无区域淋巴结转移 |
| N1 | 1-3枚淋巴结转移 |
| N2 | ≥4枚淋巴结转移 |

#### 可切除性分类
```
可切除 → 边界可切除 → 不可切除
   │              │
   └── 新辅助 ────┘
```

## 4. 治疗策略 (Treatment)

### 治疗模式

```
                    胰腺癌
                       │
        ┌──────────────┼──────────────┐
        │              │              │
    可切除          边界可切除      不可切除
        │              │              │
    手术+辅助       新辅助→手术     化疗/放化疗
        │              │              │
                       │         ┌─────┴─────┐
                       │    局部晚期    晚期
                       │         │         │
                       │      同步放化疗  系统治疗
                       │                  │
                       │            一线→二线
```

## 5. 知识关联

### 诊断-分期-治疗链条
```
CA19-9升高 → CT评估 → TNM分期 → 可切除性评估 → 治疗方案
```

### 关键决策点
1. **影像评估** → 是否可切除
2. **体能状态** → 化疗方案选择
3. **分子检测** → 靶向/维持治疗
4. **疗效评估** → 方案调整
